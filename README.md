# AURA Studio — landing page

Landing page em português, construída com React, Vite e [Glisse](https://github.com/0kzh/glisse) para os controlos Liquid Glass. O restante conteúdo usa HTML semântico e CSS responsivo.

## Desenvolvimento

```sh
npm install
npm run dev
```

Para gerar a versão estática de produção:

```sh
npm run build
npm run preview
```

## Notas antes da publicação

- Os três projetos estão identificados como estudos conceptuais e não representam clientes ou trabalhos realizados.
- `ola@aurastudio.pt` é um endereço de demonstração. Substitua-o por uma caixa de email ativa antes da publicação.
- O formulário abre o programa de email do visitante com a mensagem preenchida; não envia dados nem confirma a entrega por si só.
- As fotografias vêm do Unsplash e as fontes do Google Fonts.
